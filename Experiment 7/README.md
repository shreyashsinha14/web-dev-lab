# Experiment 7: React Notes App

**Student:** Shreyash Sinha  
**Repository:** [shreyashsinha14/web-dev-lab](https://github.com/shreyashsinha14/web-dev-lab)

## Aim
To build a Notes App using React that lets users create, search, edit, and delete notes.

## Files
- `index.html`: Loads React, ReactDOM, Babel, the stylesheet, and the React application.
- `style.css`: Responsive layout and styling for the editor and note cards.
- `script.js`: React component, form validation, note CRUD actions, search, and browser localStorage persistence.

## Features
1. Add a note with a title and text.
2. Search notes by title or text.
3. Edit and update an existing note.
4. Delete a note after confirmation.
5. Persist notes in the browser's localStorage.
6. Responsive layout for smaller screens.

## How to run
Open `index.html` in a modern browser while connected to the internet, because React and Babel are loaded from CDN links. Create a note to test saving, refresh the page to check persistence, then try search, edit, and delete.

## Result
A responsive React Notes App is implemented with create, read, update, delete, search, and local persistence features.
